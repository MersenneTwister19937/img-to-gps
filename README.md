# IMG to GPS
Took a cool picture and forgot where it was? Find the exact location through metadata with this simple python script!

# How to use
To open and run the exe, just go to **dist > main.exe** and open it.
Then, add the image you want to scan in the img directory (also inside dist) for future use.
### .jpg files are best for use, however those extracted from messaging platforms such as Discord or WhatsApp have their metadata stripped, meaning it won't work.

# For contributors
Once you are finished with your contributions, run `pyinstaller --onefile --collect-all pyfiglet main.py`
